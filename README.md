
# UD01 - Actividad 09: Gestor de Alumnos

## Descripción

Aplicación de consola desarrollada en Kotlin que permite gestionar
los datos y las calificaciones de los alumnos de un grupo.

## Funcionalidades

- Registrar alumnos con nombre, apellidos y nota.
- Listar los alumnos registrados.
- Calcular la media del grupo.
- Mostrar alumnos aprobados y suspensos.
- Buscar alumnos por nombre o apellidos.
- Eliminar alumnos de la lista.
- Validar los datos introducidos y controlar errores.

## Estructura del proyecto

- `Main.kt`: contiene el menú principal.
- `Alumno.kt`: contiene la clase de datos Alumno.
- `Funciones.kt`: contiene las funciones de gestión del alumnado.

## Tecnologías utilizadas

- Kotlin.
- IntelliJ IDEA.
- JDK.

## Ejecución

Abrir el proyecto en IntelliJ IDEA, ejecutar el archivo `Main.kt`
y seleccionar la opción deseada en el menú de la consola.
